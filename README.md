# Initial Business Insights

## 1. Order Status
Approximately 92.6% of orders have a "Shipped" status, indicating that the majority of orders were successfully processed and dispatched.

## 2. Sales Distribution
The average sales value is higher than the median, suggesting that some high-value orders increasing the overall average sales.

## 3. Yearly Orders
2004 had the highest number of orders with 1,351 orders indicating particularly strong order activity during that year.

## 4. Product Line
Classic Cars had the highest number of orders, indicating that it was the most popular product.
